# BitterCare Homepage V20

2026-10-14 · 한국어 / English / 日本語 / 简体中文 / Tiếng Việt

## 반영 내용

- 최신 한국어 화면을 공통 템플릿으로 사용하여 5개 언어의 홈과 8개 공개 페이지를 동일한 구조로 동기화했습니다. 관리자 화면은 기존 한국어 운영 화면을 유지합니다.
- 제품 소개 → 실제 사용 영상 → 사용 전 확인·FAQ → 5M/10M 구매 → 짧은 성향 선택 → 문의 순서를 유지합니다.
- 홈의 성향 팝업은 PC에서 브라우저 세션당 한 번 자동 표시합니다. 모바일에서는 본문을 가리지 않는 작은 배너로 안내하고, 사용자가 누를 때 팝업을 엽니다. 다시 보지 않기 설정과 수동 재열기를 유지합니다.
- 팝업의 한국어가 박힌 합성 이미지 대신 번역 가능한 실제 글자와 언어별 기존 앱 홍보 사진을 사용합니다. 공개 홈페이지의 문구/라벨은 선택 언어로 표시됩니다. 연결된 app.bittercare.com 검사 앱은 별도 서비스이며 기존 언어 선택 동작을 유지합니다.
- 5M/10M 구매 팝업은 해당 길이의 쿠팡·네이버·G마켓만 표시합니다. 일반 구매처 버튼은 전체 제품을 표시합니다.
- Canonical/OG URL/구조화 데이터/언어별 hreflang/사이트맵을 Cloudflare의 확장자 없는 최종 URL로 통일했습니다. 사이트맵에는 40개 콘텐츠 URL이 있습니다.
- 성격 테스트 안내 페이지를 4개 외국어로 추가하고, 모든 공개 페이지의 푸터에 해당 언어 안내 링크를 추가했습니다.
- 제품 사진 PNG를 WebP(102,382 bytes)로 최적화했습니다. 이미지 8개(9,085,032 bytes)를 V20에서만 제외했습니다. IMAGE_CLEANUP_V20.json에 목록과 판단 기준이 있습니다. 조건부 CSS/스크립트 참조가 있는 파일은 보수적으로 유지합니다.
- 초기 영상 재생은 움직임 줄이기·데이터 절약·탭 숨김·화면 밖 상태를 고려합니다.
- 누적 CSS 적용 순서를 보존하여 3종 번들로 구성했습니다. 홈의 로컬 CSS 요청은 17개에서 1개로 줄였고 외부 폰트 CSS는 별도 유지합니다.

## 배포

1. ZIP을 풀고 BitterCare_Homepage_V20 폴더 안의 파일/폴더를 저장소의 기존 홈페이지 배포 루트에 반영하세요. ZIP 파일 하나만 업로드하지 마세요.
2. 기존 파일에 덧붙이기만 하면 제외한 이미지가 저장소에 남습니다. CHANGED_FILES_V20.md와 IMAGE_CLEANUP_V20.json의 제외 목록을 기존 배포 폴더에서도 반영하세요. V19 원본에서는 복구할 수 있습니다.
3. Cloudflare Pages 배포 후 홈, 각 언어 홈, /dog-personality-test, /en/dog-personality-test, robots.txt, sitemap.xml을 확인하세요.
4. Cloudflare의 루트 도메인 bittercare.com → www.bittercare.com 영구 이동은 별도 도메인 Redirect Rule 설정 사항입니다. _redirects는 도메인 이동을 지원하지 않아 잘못된 규칙을 넣지 않았습니다. Canonical은 www로 통일되어 있습니다.
5. 문의/관리자는 기존 Cloudflare D1 바인딩과 관리자 설정이 있어야 동작합니다. 실제 고객 문의나 관리자 데이터는 이번 제작에서 제출/조회하지 않았습니다. 설치 관련 기존 README.md를 참고하세요.
6. 배포 성공 후 네이버 서치어드바이저와 Google Search Console에서 대표주소/사이트맵/색인 상태를 확인하세요. SEO 설정이 검색 노출이나 순위를 보장하지는 않습니다.

## 로컬 확인

파일로 index.html을 열어도 JS가 clean URL 링크를 물리적인 .html 파일로 변환합니다. 문의 접수는 file://에서는 동작하지 않으며 이메일 대체 경로를 사용합니다.

## 검증 범위

45개 공개 HTML의 구조/문구/언어 메뉴/링크/이미지/CSS 참조/JSON-LD 검사, 사이트맵 40개, 5개 언어 동작 테스트, JS 문법 검사를 통과했습니다. 테스트는 정적·격리 DOM 검사입니다. 이번 제작 중 별도 검증용 브라우저 사용 승인을 요청했으나 실제 브라우저 검증은 수행하지 않았습니다. PC/모바일 렌더링·실기기·문의 실접수·실결제·운영 V20 배포는 미검증입니다.
